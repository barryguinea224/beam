# Sources SVG du logo BTH

- `bth-logo.svg` : tracé vectoriel modifiable du globe doré et du carnet ouvert, sur fond vert foncé à coins arrondis.
- `bth-maskable.svg` : même symbole sur fond vert plein pour une icône Android recadrable.

L'image de référence **choisie par le propriétaire** est `../icon-192.png` (192 × 192). Les PNG 512 × 512 sont dérivés de ce fichier (et non des tracés SVG approximatifs) par `scripts/render-bth-icons.py`. Le fichier `icon-maskable-512.png` possède un fond opaque plein et le symbole reste dans la zone centrale de sécurité.

Ces fichiers SVG sont des tracés éditables reconstitués à partir du PNG source ; ils ne prétendent pas être les fichiers maîtres originaux du designer. Les chemins et noms du manifeste ne changent pas.
